# Before/after comparison images - method note

Files: compare-a-hospital.png (Sample A, top fold) and compare-b-dashboard-full.png (Sample B, full page).

## What these images are
A reconstructed styling comparison. Both sides were rendered at the same 1440px
viewport with the same fictional copy and data.

- ILLUSTRATIVE BASELINE (left): the same content styled with plain defaults -
  system font, default link blue, simple gray boxes, standard spacing. Built as
  an honest baseline for comparison. It is not a historical screenshot, and it
  is not deliberately broken or uglified.
- GUIDE-STYLED DEMO (right): the same content styled by following SKILL.md
  (palette with named shades and roles, deliberate font pairing, spacing scale,
  status pills, consistent components).

## What these images are not
- Not historical before/after screenshots. No earlier versions of these samples
  existed; the baseline was reconstructed for this comparison.
- Not an independent effectiveness test. No users, metrics or business results
  were measured. The images show styling differences only.
- Not a claim that one density or layout is universally better. The guide-styled
  versions use more generous spacing and a themed look; which is preferable
  depends on the product and audience.
